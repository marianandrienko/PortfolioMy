# Сайт-портфоліо вчителя інформатики

Сайт оформлений у стилі попереднього портфоліо на uCoz. Він публікується через GitHub Pages. Уроки та матеріали керуються через [Pages CMS](https://pagescms.org/) і зберігаються в `content/lessons.json`.

## Як додавати й редагувати уроки

1. Увійдіть у [Pages CMS](https://pagescms.org/) через GitHub і надайте їй доступ до репозиторію `marianandrienko/PortfolioMy`.
2. Відкрийте колекцію **«Уроки та матеріали»**. Створіть запис або виберіть існуючий для редагування.
3. Укажіть назву, категорію, опис і текст матеріалу. Доступні конспекти 9–11 класів, практичні роботи, презентації, тести, інтерактивні завдання та документи вчителя.
4. У блоці **«Документи та презентації»** додайте матеріал: завантажте файл або вставте посилання для спільного доступу з Google Drive чи OneDrive.
5. Збережіть зміни в основній гілці. GitHub Pages оновить сайт автоматично після публікації.

Посилання на Google Документи й Презентації відображаються на сторінці матеріалу та, коли формат посилання це дозволяє, відкриваються у вбудованому переглядачі. Для OneDrive можна вставити посилання на матеріал; доступність вбудованого перегляду залежить від налаштувань спільного доступу.

Файли, завантажені до репозиторію, стають публічно доступними разом із сайтом. Завантажуйте лише матеріали, які дозволено оприлюднювати.

У розділі **«Матеріали та публікації»** зібрано вибрані матеріали з особистого [блогу на Всеосвіті](https://vseosvita.ua/user/id1383056/blog): навчальні програми, курси, підручники, нормативні документи та відзнаки. Посилання в картках ведуть до першоджерел і доступних файлів.

## Індексація в Google

Сайт містить метадані для пошукових систем, файл `robots.txt` і карту сайту `sitemap.xml`. Щоб повідомити Google про сайт:

1. Увійдіть до [Google Search Console](https://search.google.com/search-console/) зі свого Google-акаунта та додайте ресурс **префікс URL** `https://marianandrienko.github.io/PortfolioMy/`.
2. Підтвердьте право власності способом, який запропонує Search Console. Для цього може знадобитися додати на сайт HTML-файл або метатег перевірки з наданим Google кодом.
3. У Search Console відкрийте **Файли Sitemap**, введіть `sitemap.xml` і надішліть карту. Після підтвердження права власності можна скористатися **Перевіркою URL** та запросити індексацію головної сторінки.

Додавання карти сайту не гарантує миттєвої появи сторінки в результатах пошуку: Google самостійно вирішує, коли і які сторінки індексувати.
